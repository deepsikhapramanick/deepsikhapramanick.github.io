# Deepsikha Pramanick — Portfolio v2

Static, GitHub Pages-ready portfolio based on the finalized minimalist scientific/research design.

## Files

- `index.html` — homepage
- `projects.html` — project archive
- `gallery.html` — project/conference visual gallery
- `certificates.html` — certificates and achievements
- `updates.html` — WhatsApp-status-style recent updates
- `research.html` — research interests + research group link
- `blog.html` — research blog archive
- `about.html` — longer biography
- `assets/css/styles.css` — complete design system
- `assets/js/main.js` — navigation, filters and gallery lightbox
- `assets/images/` — replaceable placeholders

## Design system

Background `#FAFAF8`
Text `#202124`
Muted `#5F6368`
Border `#E8E8E5`
Sky blue `#63B3ED`
Soft pink `#F3A6C8`
Coral `#F47C7C`

Typography: Inter + IBM Plex Mono.

Desktop reference: 1440px wide, 12-column layout, 72px outer margin, 24px gutter.

## How to customize

1. Replace placeholder SVGs in `assets/images/` with your own images, keeping filenames or changing the corresponding HTML paths.
2. Update project cards in `index.html` and `projects.html`.
3. Update social links in the shared footer.
4. Replace the research-group name and URL in `research.html`.
5. Add real status entries to `updates.html`.
6. Add certificate cards to `certificates.html`.
7. Add blog posts to `blog.html`.
8. Add your CV link if desired.
9. Push the folder to a GitHub repository and enable GitHub Pages.

No server-side code is required.
